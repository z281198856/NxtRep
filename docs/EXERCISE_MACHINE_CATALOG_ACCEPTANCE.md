# 史密斯及固定器械动作库扩充

## 范围

本轮在现有公共动作库中新增 28 个动作，数量从 46 增至 74；为原有史密斯上斜推胸补齐资料，并填补 6 个基础动作的空说明。沿用已有 API、模型、训练服务和确认机制，不增加表，不改写训练历史和用户自定义动作。

新增动作包括：

| 类别 | 新增动作 |
| --- | --- |
| 史密斯机（8 个新增，另完善原有上斜推胸） | 平板卧推、下斜卧推、坐姿推肩、深蹲、罗马尼亚硬拉、保加利亚分腿蹲、臀推、站姿提踵 |
| 固定器械（17 个新增） | 上斜推胸机、蝴蝶机夹胸、反向蝴蝶机飞鸟、器械侧平举、胸托划船机、腿举机、哈克深蹲机、坐姿腿屈伸、坐姿腿弯举、俯卧腿弯举、坐姿髋外展、坐姿髋内收、坐姿提踵机、臀推机、器械牧师凳弯举、器械三头臂屈伸、器械卷腹 |
| 杠铃（3 个新增） | 罗马尼亚硬拉、上斜卧推、臀推 |

每个新增动作包含：中文名称、常见中英文别名、器械、运动模式、主练与辅助肌群、操作步骤、呼吸提示、常见错误和安全提示。旧动作的 ID、版本和记录快照保持不变，已有史密斯上斜卡片可继续确认。

补齐空说明的基础动作为：杠铃深蹲、杠铃卧推、传统硬拉、杠铃划船、站姿杠铃推举、高位下拉；已有非空说明不覆盖。

## 解剖图与页面

复用现有 Flutter 肌群高亮与动作方向组件，图示在本地绘制，不依赖外部图片下载。新增腿举、伸膝、坐姿/俯卧屈膝、坐姿髋内收/外展、站姿/坐姿提踵、臀推和器械卷腹的姿态及说明。图中红色标出主练肌群，黄色标出辅助肌群，绿色表示动作方向。

史密斯显示固定导轨、横杆和凳面支撑；固定器械上肢动作显示座椅与杠杆。新增“史密斯机”筛选及中文器械名称，支持自定义动作器械选择。腿弯举不会套用手臂弯举图，分腿蹲优先识别为分腿动作。

这些是二维肌群和动作方向示意，品牌机型的结构、导轨角度和调节机构以具体设备为准。上斜/下斜差异由动作名称、图示文字和操作步骤说明。

## App 验收

动作库已有两个直接入口：首页“快速开始”右侧的“动作库”按钮，以及“计划”页标题右侧的“动作库”按钮。原来推荐计划下方的卡片已移除；两个按钮打开同一个动作库页面。计划页日历仍靠前展示。

1. 从首页或计划页点击“动作库”；横向滑动器械筛选栏选择“史密斯机”，应看到 9 个史密斯动作。
2. 搜索“史密斯推肩”，打开“史密斯坐姿推肩”，检查肩部主练高亮、推举方向和操作步骤。
3. 搜索“史密斯上斜推胸”，检查其名称、胸部高亮、固定导轨、上斜凳文字和完整说明。
4. 搜索“倒蹬机”，应找到“腿举机”；分别打开“坐姿腿屈伸”“坐姿腿弯举”，比较伸膝与屈膝图示方向。
5. 搜索“坐姿髋内收”“坐姿髋外展”，图示应分别向内夹合、向外打开，主练肌群标签不同。
6. 可在 AI 中使用明确日期、动作和重量组次生成待确认卡，例如“今天史密斯坐姿推肩20kg，3组，每组10次”。若有其他日期的进行中训练，需明确选择追加哪场训练；本轮不绕过该日期与确认校验。

## 边界

本轮扩充公共动作库及其展示内容，没有实现 Agent 自动创建所有库外动作。器械品牌和型号众多，同类动作的具体调节方式仍有差异。数据迁移回退时保留动作条目，避免已经被计划、训练或待确认卡引用的数据失效。
