# 月日历与简洁来源展示

本轮依据用户反馈完善现有界面，没有增加新的 Agent 框架或修改业务确认规则。

## 本轮变化

- 「计划」顶部直接显示整月训练日历，支持上个月、下个月与回到今天。星期一开始，今天描边、所选日期高亮；训练安排按待训练、已完成、未完成、已跳过显示圆点，使用后端真实状态。
- 月份切换读取该月第一天至最后一天的真实日历；刷新和修改训练后仍读取当前月份。旧请求晚返回不会覆盖新月份。加载失败明确显示错误，不能当成无安排。
- 点日期后显示当天全部训练，继续复用已有手动安排、改期与压缩入口。计划内容、推荐和训练历史继续在下方查看。
- AI 回复正文展示有用结论，搜索来源最多一条小号网站链接；不展示查询时间、缓存字段、原始来源列表与长网址。历史回复的旧附录在显示时收起，原消息和检索审计保留。
- 来源只支持HTTP(S)，拒绝带认证信息的链接；打开失败提示并提供复制完整链接。

## App 验收

1. 打开底部「计划」，首屏应看到「训练日历」和完整月份，不需要先翻过推荐计划。
2. 翻到上个月、下个月，点日期核对当天记录；点「今天」回到当前日期。下拉刷新后不要自动跳回其他月份。
3. 有训练的日期显示圆点；同一天有多场训练时，下方应全部显示。日期没有安排时可手动加入；读取失败时应显示错误而非「暂无安排」。
4. 打开原来带「查询时间」和长网址的 AI 回复，正文应收起旧来源附录，下面最多一条小链接。
5. 新问「力量训练后怎样恢复？资料不足时补充公开来源」，检查自然中文回答和底部来源行。链接点击应调起浏览器，不在聊天中展开完整网址或搜索结果JSON。
