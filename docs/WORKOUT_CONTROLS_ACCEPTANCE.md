# 训练中组数、动作与休息计时验收

本轮范围：开始训练后的组数修改、计划/自主训练入口、动作追加和可调休息倒计时。

## 原因与改动

- 后端的实际目标组数字段是 `target_snapshot.sets`，旧前端却读取 `target_sets`，因而可能固定显示为默认 3 组，并过早停用记录按钮。现在正确读取并兼容旧字段。
- 旧训练页没有目标组数修改入口。现在点击动作卡右上方的“已完成/目标 组”可修改；已完成后增加目标，也能继续记录。
- 首页“按计划训练”沿用日历和计划快照；新增“自主训练”可直接开始空训练。计划训练显示“临时添加动作”，自主训练显示“添加第一个动作/下一个动作”。
- 总用时与休息倒计时并排固定显示在页头。成功记录一组后启动该动作的休息计时，点击计时区或动作卡“休息”可输入秒数或选择常用值；0 秒关闭。
- 休息时长仅针对本次训练的这个动作，当前倒计时按最近一组完成时间重新计算；暂停/继续时冻结/恢复，重新进入可从后端恢复。
- 删除组后再添加不再复用已作废的组序号，避免数据库唯一约束冲突。

复用现有 Workout、WorkoutExercise 快照、业务 Service、版本锁和写入幂等，没有数据库迁移。
新增轻量目标修改接口，保持现有接口兼容，不修改原计划或正式用户的历史记录。

## App 手动验收

1. 首页点“按计划训练”→填写训练前状态→开始。检查动作组数与原计划一致。
2. 点某动作右上角组数，把 4 改成 5；记录一组重量/次数，检查变成 1/5。
3. 检查总用时旁的组间休息自动倒数；点休息计时，输入 75 秒或选择常用值。
4. 暂停两三秒后继续，确认总计时、休息倒计时均正确暂停/继续。
5. 返回首页再点“继续训练”，核对组数、记录和休息设置仍在。
6. 达到目标组数后再次增加目标，检查可以继续记下一组；降低到已完成组数以下会被阻止，已完成记录保留。
7. 结束本次训练后，从首页选“自主训练”，添加第一个动作；用“下一个动作”追加，确认新动作没有继承前一动作的已完成组、重量或次数。
8. 按计划训练仍可临时添加动作；到计划详情检查原计划组数未改变。
